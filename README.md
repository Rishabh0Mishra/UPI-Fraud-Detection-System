# UPI Real-Time Fraud Detection System

A production-ready, real-time UPI (Unified Payments Interface) fraud detection system featuring LightGBM + graph-based ring detection + ensemble scoring, served via a FastAPI inference API.

## Architecture

```
data/                          ← Raw data files
├── upi_transactions.csv       (500K transactions)
├── upi_fraud_labels.csv       (3,636 fraud labels)
├── upi_user_profiles.csv      (50K user profiles)
├── upi_merchant_profiles.csv  (5K merchant profiles)
└── upi_fraud_rings.json       (23 fraud rings)

models/                        ← Generated by pipeline
├── lgbm_fraud_model.pkl
├── model_config.json
├── ensemble_config.json
├── score_calibrator.pkl
├── graph_node_features.parquet
├── graph_risk_scores.pkl
├── feature_importance.csv
├── shap_summary.png
└── threshold_analysis.png

01_feature_engineering.py      ← Step 1: Feature engineering (~55 features)
02_model_training.py           ← Step 2: LightGBM 5-fold CV + SMOTE
03_graph_features.py           ← Step 3: NetworkX graph + ring risk scores
04_ensemble.py                 ← Step 4: Ensemble + calibration + thresholds
api/05_realtime_api.py         ← Step 5: FastAPI real-time scoring server
```

## Key Features

| Feature | Description |
|---|---|
| **55+ engineered features** | Amount ratios, time patterns, velocity, biometrics, ring membership |
| **LightGBM + SMOTE** | Handles 136:1 class imbalance with stratified CV |
| **Graph ring detection** | NetworkX PageRank, HITS, SCC, Louvain community detection |
| **3-tier decisions** | BLOCK / REVIEW / ALLOW with calibrated probabilities |
| **Hard block rules** | Instant blocking for known controllers, intra-ring transfers, fake merchants |
| **SHAP explainability** | Regulatory-compliant feature explanations |
| **<50ms API latency** | FastAPI with pre-loaded models and O(1) lookups |

## Setup

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Ensure data files are in ./data/

# 3. Run full pipeline
python 01_feature_engineering.py    # ~5-10 min (rolling features)
python 02_model_training.py         # ~5-15 min (5-fold CV)
python 03_graph_features.py         # ~2-5 min (graph construction)
python 04_ensemble.py               # ~1-2 min (calibration)

# 4. Start API server
cd api
uvicorn 05_realtime_api:app --host 0.0.0.0 --port 8000 --workers 4
```

## API Usage

### Score a transaction
```bash
curl -X POST http://localhost:8000/score \
  -H "Content-Type: application/json" \
  -d '{
    "transaction_id": "TXN_TEST_001",
    "sender_user_id": "USR005112",
    "receiver_id": "USR033087",
    "amount": 85000,
    "transaction_type": "P2P",
    "sender_avg_txn_amount": 500,
    "sender_vulnerability_score": 0.8,
    "sender_account_age_days": 15
  }'
```

### Health check
```bash
curl http://localhost:8000/health
```

### Detection stats
```bash
curl http://localhost:8000/stats
```

## Fraud Types Detected

| Type | Signal |
|---|---|
| Vishing | Large amount + off-hours + high vulnerability |
| Social Engineering | Unusual receiver + round amounts |
| Account Takeover | Device change + immediate large transaction |
| QR Scam | P2M to unverified merchant |
| Fake App | Non-legitimate app package |
| Money Mule | Intra-ring transfers + hub-spoke topology |
